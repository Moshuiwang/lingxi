### 正式验收 / 发布对象合同

- **对象规则**：**合并后由已验收树产生的不可变镜像**。本 Trace 的正式验收对象 = **批次 3 合并 `main` 后 `Main Publish` 产出的那一组 tag `YYYYMMDD-<sha12>` 镜像**（scheduler / migrate / gateway / worker 四个）。
- **构建链**：批次分支 → `Epic Full` 全绿（候选证明写入 run artifact）→ 合并 `main` → `Main Publish` 读 artifact 做 tree 比对 → 构建并推 GHCR。
