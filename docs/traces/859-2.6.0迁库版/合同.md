- **里程碑（何谓「到了」）**：① 生产跑 v2.5.3，生产代理 sha256 = v2.5.3 控制包内代理，预发已真机证明「新包代理 ≠ 在位代理 → 自替换 → 下一轮由新代理运行」，#838 / #856 在预发真机各触发一次告警并恢复静默；② 生产三服务跑 v2.6.0 且连接的是本地 PostgreSQL 17（`inet_server_addr()` 为本机、对象 / 行数与迁移前一致、alembic head 0098 或更新），**产品负责人 Bot-Prod 一次真实问数（L5）**，每日备份定时器连续 7 天成功、副本落 biai-stage、一次从副本恢复到独立实例成功，7 天无数据差异与告警；③ tx-sg 串行门禁与 tz 同一提交结论一致，配置无写死；迁移链检查成本随 revision 线性且变异验红。
