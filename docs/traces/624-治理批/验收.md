## 就绪自检模板（每个 PR 合并前逐项写现值）

1. 本机检查绿并见输出行（`check.sh docs` 或 `full`），退出码回读
2. 分类器判定的路由（`docs` / `fast`）与本次消耗的 Epic Full 次数（累计 / 5）
3. 独立审核结论：P1 为零或全部进修复包；P2 有去向或豁免留痕
4. 该 PR 是否触碰 `合同.md`（触碰则须产品负责人本人批准，不得自合）
5. main 未被他人推进、无其他开放 PR 冲突；`ux-b2` 未启动
