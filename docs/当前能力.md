## 当前状态

- 本项目已建立跨设备、跨代理的协作入口：GitHub Project、中文 Issue 标签、Issue 表单、PR 模板及仓库级 AI 规则。

- 四项外部依赖目前均为产品约束，具体接入能力、权限口径和可用性必须在相关 GitHub Issue 中确认后才能写入本文件。

## 已验证的飞书关联组织边界

以下为 2026-07-23 使用 `StarTimes` 自建应用与关联免费租户进行的接口验证；它们是身份方案的输入，不代表 Lingxi 用户注册、问数或文档交付能力已经上线。

- 中心应用可用应用身份遍历关联组织共享范围，获得共享成员的 Bot `open_id`，并已验证可向该 ID 发起跨租户 Bot 单聊。
- 中心应用不能用工作邮箱直接在关联组织中检索成员，也不能以应用身份通过标准通讯录资料接口读取关联组织成员邮箱。
- 用户完成飞书授权后，可用用户身份从关联组织接口获得该用户的 `user_id`、`open_id` 与 `union_user_id`；已验证的响应不含标准邮箱字段。
- 用户身份令牌是短期凭据，只能用于一次性身份绑定；不得作为持久会话凭据、日志字段或用户交付物保存。
- 详细证据、接口与历史推荐注册鉴权流程见[飞书关联组织身份与注册鉴权参考证据](参考证据/飞书关联组织身份与注册鉴权-handoff.md)。
