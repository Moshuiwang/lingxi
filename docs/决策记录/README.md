## 何时建立记录

仅在以下情况建立一份记录：

- 选择改变或明确了用户体验、业务规则、权限、安全或外部依赖的长期口径；并且
- 未来实施、运营或新成员需要知道“为什么按这个规则做”。

纯实现取舍、一次性排障和已被否决的方案不建记录，保留在 Issue / PR 即可。

## 文件与状态

文件名使用 `YYYY-MM-DD-主题.md`。每份记录只使用下列状态之一：

- `现行`：当前仍适用。
- `已替代`：在正文首段链接替代它的记录。
- `已撤销`：说明撤销原因与生效范围。

一项决策若同时改变产品承诺或已确认能力，还必须更新[产品合同与外部边界](../产品合同与外部边界.md)或[当前能力](../当前能力.md)；决策记录不能替代这两份面向全体读者的总览。
