# 决策：自动准入以数据库权限为准并通过多维表格发布

> 状态：现行
> 决定日期：2026-07-26
> 来源：[GitHub Issue #7](https://github.com/Moshuiwang/lingxi/issues/7)；产品负责人于 2026-07-26 确认权限权威与发布通道

## 要解决的长期问题

Lingxi 首次面对一名飞书用户时，需要确认该用户是谁、可以访问哪些公司和职能，并把正确权限发布给 MCP。数据库、飞书多维表格和 MCP 分别保存不同阶段的状态，必须明确谁决定权限、谁只负责传递，以及状态不一致时用户能否继续问数。

## 已接受的规则

- Lingxi 生产数据库是正式用户权限、公司和职能范围、启停状态的唯一权威来源。
- 用户尚未开通时，无论发送什么内容，系统都只回复产品介绍和“回复‘确认’开始开通”的统一欢迎语；除精确的“确认”外，其他内容不进入业务对话、不触发问数，也不保留为开通后的首个问题。
- 用户回复“确认”后，系统自动取得飞书允许提供的中文姓名、`open_id`、`user_id`、`union_id`、部门和租户等必要信息。
- 产品负责人提供的银河用户数据先通过受控流程进入 Lingxi 生产数据库；收到用户“确认”后，系统立即用本次飞书身份与数据库当前有效记录进行匹配，不要求首批用户事先逐人完成身份核对，也不把预核对白名单作为上线门槛。
- 首期以飞书中文姓名与数据库中当前有效的用户权限记录进行匹配。只有唯一命中且权限记录完整时才自动通过；未查到、重名或信息不完整时暂停并交由管理员核对。
- 正常路径不要求用户填写权限申请或等待人工审批。首次开通过程可以包含自动核验、用户环境创建、权限发布和可用性确认；只有异常才转人工处理，管理员只能确认正确数据库记录或终止创建，不能借此扩大数据库权限。
- 飞书多维表格只是数据库向 MCP 发布权限的下游通道。它不能创建、修改或扩大数据库权限，也不能反向成为授权依据。
- 只有数据库权限、飞书多维表格发布结果和 MCP 实际生效状态一致且均得到明确确认后，用户才可以问数。
- 开通成功后系统通知用户可以开始使用，并展示当前可用的公司和职能范围；系统不自动执行开通前发送的内容，用户重新发送第一条业务问题后才进入问数。
- 发布失败、状态不一致或结果不明时，系统暂停查询并向用户说明正在处理；运维核对实际状态后从未确认步骤安全恢复，不盲目重复发布。
- 新增权限只有在数据库更新、发布完成和 MCP 实际可用均得到确认后才向用户宣告生效；权限收回、离职或账号停用一经数据库确认立即阻止相关新查询和新交付。
- 正在执行的任务如涉及刚被收回的范围应停止；恢复账号时不自动恢复已收回权限。每次变化都通知用户本人当前仍可使用的范围。
- 本决策只确定权限权威和发布关系，不选择数据库产品、托管位置、备份方案或具体表结构；这些属于后续实施工作。

## 对用户和边界的影响

- 用户的数据范围只由数据库当前有效记录决定，不会因为飞书多维表格被误改、残留旧值或 MCP 状态异常而被扩大。
- 正常用户首次私聊后可等待系统自动开通，不需要理解数据库、多维表格或 MCP。
- 产品负责人提供银河用户数据后，不需要再为首批名单逐人做预核对；用户回复“确认”时触发实时匹配，只有异常用户进入人工处理。
- 即使数据库中已有权限，只要发布或 MCP 生效尚未确认，用户也不会收到虚假的“已经可以使用”。
- 进入人工核对的用户在一个工作日内至少收到一次明确进展或最终结论；这是服务承诺，不代表 Lingxi 自动催办或代替人工处理。
- `user` 用户表只保存身份关联、权限判断、发布状态、服务和审计所必需的信息，不保存短期令牌或认证材料。

## 不采用的选择及原因

- **把飞书多维表格作为权限权威**：它是发布通道，误改或同步延迟不能改变用户应有权限。
- **直接用银河导出名单作为运行时权限权威**：任何上游信息都必须经过受控流程进入数据库，运行时只认数据库当前有效记录。
- **以 MCP 当前状态反向覆盖数据库**：MCP 是权限执行端，异常或旧状态不能成为授权决定。
- **模糊姓名匹配或自动选择同名记录**：存在把其他人的权限授予当前用户的风险。
- **所有用户都等待人工审批**：唯一有效匹配时继续人工处理没有用户价值。
- **把用户首次发送的业务问题自动排队到开通后执行**：用户尚未确认开通，该内容不应进入业务处理或后续会话；开通成功后由用户重新提问更清晰。

## 复审或替代条件

出现以下情况时必须重新评估本决策：

- 权限数据库的治理责任或权威地位发生变化；
- 中文姓名唯一匹配在实际运行中产生不可接受的错配风险，或出现更可靠的稳定身份标识；
- 飞书多维表格不再承担权限发布通道；
- MCP 的权限发布或生效确认机制发生变化；
- 公司要求所有用户重新引入人工审批。
