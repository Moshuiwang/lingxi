# 内测管理通道安装契约

本契约固定控制包与 scheduler 接口，不是部署器，也不授权真实安装。三工具仅查询和准备，本人飞书确认才新增资格。真实安装及平台旅程仍待验收。

- schema revision：1；relay 为 `scripts/admin/innertest_relay.py`，自检为 `scripts/admin/innertest_install_check.py`，均纯标准库；宿主 Python ≥3.11，以 root 维护的绝对路径执行 `-I -S`，不现场安装依赖。
- scheduler 实现为 `adapters/innertest_mcp.py` 与 `adapters/innertest_socket.py`，不增加业务镜像。MCP `2025-11-25`，NDJSON；initialize → notifications/initialized → tools/list / tools/call，另允许 ping。其他版本/方法拒绝。三工具严格输入见 `core/admin/innertest.py`；JSON-RPC ID 不承担业务幂等，准备必须 request_key。
- socket 挂载目录由 root 或 scheduler UID 持有，0750，SSH 主体仅目录搜索权；socket 0660，固定受限组仅连接权。目录不能组写，不挂 Docker socket。listener 单线程、最多4连接、64KiB、每个请求5秒；与阶段共用两槽预算，自身串行至多一槽，纳入 scheduler 共同120秒截止。
- relay UID 与 scheduler UID 必须不同；不得使用 root/65534。Linux SO_PEERCRED 取得容器观测 UID；保护配置同时固定 host_uid、peer_uid 和 `/proc/self/uid_map` 原字节 SHA256，实际映射不等即拒绝。不能把未知 UID 自动绑定当前唯一管理员。
- root 管理绑定文件与全部父目录，禁止符号链接和组/其他写；文件 schema 为 `schema_revision,binding_id,host_uid,peer_uid,uid_map_sha256,socket_gid`。数据库绑定每个请求/确认现读启用与版本，admin_registry 独立提供角色；配置不授角色。撤销密钥必须同步禁用数据库绑定，已有连接/旧卡随即拒绝。
- relay 相邻 `innertest-relay.json` schema：`schema_revision=1,socket_path,relay_uid,socket_owner_uid`，固定绝对 socket 路径。stdin 字节只转发，不执行 SSH_ORIGINAL_COMMAND、不接受路径/环境/命令参数。stdout 只有协议，诊断 stderr 脱敏。
- authorized_keys 由 root 管理，专用密钥仅归唯一管理员本人；模板为 `restrict,no-user-rc,command="<冻结Python绝对路径> -I -S <冻结relay绝对路径>" ssh-ed25519 <公钥>`。sshd 对专用账号另固定 DisableForwarding yes、PermitTTY no、PermitUserRC no、X11Forwarding no，禁密码认证；无 sudo 授权、无 docker/sudo/wheel 组。账号不能修改 Python/relay/绑定/authorized_keys/父目录。
- 自检输入 schema：`schema_revision,python,relay,relay_sha256,relay_config,binding,socket_directory,relay_uid,relay_gid,authorized_keys`；JSON输出 ok/errors/manual_required。sudo 与 sshd 生效策略、密钥本人归属以及合法账号/错UID/容器内非授权进程三路连接仍须实际核验，机器自检不能替代这些事实。

控制包 Owner 负责冻结源码摘要、配置模板/实际非秘密映射摘要及镜像关联；真实 SSH 账号、密钥和绑定写入属于独立批准安装。未知发卡按原 request_key 查询，不通过换键再次发送。
