# 飞书话题标题命名规则（standard-light）

更新时间：2026-06-16

## 问题

飞书话题列表当前容易展示“BI Plus：已完成，用时多少秒”或直接复述用户追问。用户回到话题列表时，看不出这个话题原本在讨论什么。

## 目标体验

话题标题表达任务意图，而不是执行状态。

示例：

- `BI Plus：尼日利亚近 7 天充值金额`
- `BI Plus：乌干达近期收入`
- `BI Plus：充值趋势图`
- `BI Plus：经营分析文档`

## 规则

1. 首个有效业务问题生成会话标题。
2. `继续`、`你没给我结果`、`好的你继续`、`/new` 这类追问不覆盖已有标题。
3. 标题控制在短句内，优先保留国家/地区、时间、指标、产物类型。
4. 完成状态继续放在卡片正文底部，不放进话题列表标题。
5. 本轮不新增数据库字段，复用 `codex_chat_conversations.title`。

## 验收标准

- 用户问“尼日利亚最近一周的充值金额”时，会话标题保存为 `尼日利亚近 7 天充值金额`，卡片标题展示为 `BI Plus：尼日利亚近 7 天充值金额`。
- 同一话题后续回复“好的，你继续啊”或“你没有给我结果”时，不覆盖原业务标题。
- CardKit 关闭摘要不再使用 `已完成 · 用时 X 秒`，避免话题列表只看到执行状态。
