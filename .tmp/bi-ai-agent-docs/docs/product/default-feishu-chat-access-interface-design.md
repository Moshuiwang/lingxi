# 默认飞书聊天准入接口设计

> 日期：2026-06-26
> 状态：待实现
> 对应 PRD：`docs/product/default-feishu-chat-access-prd.md`

## 1. 申请表单

用户私聊发送“申请权限”后，直接进入申请表单。

表单字段：

- 姓名
- 工作邮箱
- 申请公司
- 职能
- 申请说明
- 是否额外申请高级数据分析工作台，默认否
- 高级工作台用途说明，仅在选择“是”时展示或要求

不展示：

- 入口类型选择
- 是否开通飞书聊天
- SSH key
- EC2 用户名
- JumpServer 信息

## 2. 高级工作台选项文案

```text
是否额外申请高级数据分析工作台？

默认不开通。日常问数、看趋势、获取分析结论可以直接在飞书聊天完成。
如果你需要持续深度分析、沉淀过程、复用 skill 或未来自动发送任务，可以选择开通高级工作台。
```

## 3. 用户确认卡

```text
请确认你的 BI 权限申请

公司：Uganda
职能：运营
飞书聊天：审批通过后默认开通
高级数据分析工作台：未申请 / 已申请
申请说明：...
```

## 4. 审批卡

```text
权限申请审批

申请人：张三（zhangsan@startimes.com.cn）
本次申请：Uganda / 运营
飞书聊天：默认开通
高级数据分析工作台：未申请 / 已申请
申请说明：...

审批通过后，用户可在原飞书私聊继续问数。
```

审批按钮：

- 通过
- 拒绝

不提供分段审批按钮。

## 5. 通过通知

只申请飞书聊天：

```text
你的 BI AI Agent 权限已通过。

现在可以直接在这个飞书私聊里继续问数、看趋势和获取分析结论。
```

申请了高级工作台：

```text
你的 BI AI Agent 权限已通过。

你现在可以直接在这个飞书私聊里继续问数。
高级数据分析工作台登录入口会继续交付；如需 JumpServer 权限，审批群或运维会继续处理。
```

高级工作台准备失败，但飞书聊天可用：

```text
你的 BI AI Agent 飞书聊天权限已通过，可以继续在这个私聊里问数。

高级数据分析工作台登录入口暂未交付成功，管理员会检查登录材料或 JumpServer 授权。
这不影响你先使用飞书聊天。
```

## 6. 拒绝通知

```text
你的 BI AI Agent 权限申请未通过。

如需重新申请，请根据审批意见补充说明后再次提交。
```

拒绝是整体拒绝，不出现“飞书聊天拒绝 / 高级工作台通过”这类分段结果。
