# 选择性生产用户迁移

## 目标

把已确认的正式内测用户从研发环境迁入生产环境，使他们在切流后能直接从飞书开始新的聊天，并保留基础文件交付能力。

## 用户体验

- 迁入用户无需重新申请权限；切流后从新的聊天会话开始。
- 不迁移历史聊天、旧会话、问数结果或高级工作台入口。
- 测试账号、未纳入名单的用户和旧目录用户绝不进入生产。

## 成功标准

- 仅迁移明确名单中的 approved 用户。
- 每位迁入用户在生产端拥有 Linux 运行身份和 `/home/biai-agent/users/<username>` 新式 home。
- 用户在生产端保留可用的 Agent 配置项和基础文件交付状态；Claude CLI 路径及版本按生产受控基线重建。MCP Token 仅保障连接身份，权限由外部审批系统负责。
- Linux 身份不开放 SSH shell；文件交付优先使用生产 User + Chat 配置绑定，并兼容旧审批流。
- execute 必须通过授权 ID 与受控 HTTPS endpoint 门禁。
- 来源目录、身份映射、连接身份或目标冲突不可判定时，整批停止。单个 Linux 创建、MCP 配置或聊天启用失败时，保留已成功用户，失败用户保持禁用并退出本批。

## 非目标

- 不迁移 SSH、JumpServer、高级工作台、历史会话或聊天内容。
- 不直接复制研发数据库，也不迁移测试账号或任何权限发布状态。
