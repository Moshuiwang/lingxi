# 候选验收记录

本目录存放每个候选版本的验收结论，文件名为 `<候选标签>.json`（例如 `v2.4.0-rc.42.json`）。

**它决定正式发布资格**：`Release Promotion` 在提升前读取本目录，找不到对应候选的验收记录就拒绝提升。字段格式与填写要求见上级目录的 [版本发布操作](../README.md)「验收后提升」一节。

两条不能绕的规矩：

- **记录必须针对候选附件里的四个镜像**，不是针对源码或某次本地构建。
- **本目录由 CODEOWNERS 保护**，改动需产品负责人本人批准；`scripts/ci/check_release_flow.py` 会核对这条保护仍然存在。

占位符内容不能直接用于提升。验收未通过时同样留记录，写明结论与证据链接，不要删文件重来。
